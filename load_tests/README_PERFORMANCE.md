# 📊 Тестирование производительности рекомендаций

Детальное тестирование производительности endpoint `/api/v1/recommendations` с разбивкой времени выполнения по компонентам.

## 🎯 Возможности

Новый функционал позволяет получить детальные метрики производительности для каждого компонента системы:

- **Redis**: время проверки и сохранения кэша
- **ClickHouse**: время выполнения каждого запроса (проверка пользователя, подсчет взаимодействий, поиск похожих пользователей, получение рекомендаций)
- **Алгоритм**: время обработки результатов
- **Общее время ответа**: суммарное время выполнения запроса

## 📝 API Changes

### Новый параметр запроса

В `RecommendationRequest` добавлен новый параметр:

```json
{
  "user_id": 1001,
  "top_n": 10,
  "exclude_listened": true,
  "include_performance_metrics": true  // 👈 Новый параметр
}
```

### Расширенный ответ

В `RecommendationResponse` добавлено опциональное поле `performance_metrics`:

```json
{
  "user_id": 1001,
  "recommendations": [...],
  "generated_at": "2025-11-10T12:00:00",
  "algorithm": "collaborative_filtering",
  "performance_metrics": {
    "total_time_ms": 245.67,
    "redis_check_time_ms": 2.34,
    "redis_save_time_ms": 3.12,
    "clickhouse_user_check_time_ms": 15.23,
    "clickhouse_interactions_count_time_ms": 12.45,
    "clickhouse_similar_users_time_ms": 89.56,
    "clickhouse_recommendations_time_ms": 123.78,
    "algorithm_processing_time_ms": 4.21,
    "cache_hit": false,
    "similar_users_count": 50
  }
}
```

## 🚀 Запуск тестов

### Быстрый тест (10 запросов)

Для быстрой проверки производительности выполните:

```bash
make load-test-recommendations-quick
```

или напрямую:

```bash
k6 run load_tests/k6_quick_performance_test.js
```

**Что покажет:**
- ✅ Среднее время выполнения каждого компонента
- ✅ Hit Rate кэша
- ✅ Распределение времени между компонентами
- ✅ Детали первых 5 запросов

### Полный анализ (~11 минут)

Для детального анализа производительности под различной нагрузкой:

```bash
make load-test-recommendations
```

или напрямую:

```bash
k6 run load_tests/k6_recommendations_performance_test.js
```

**Что включает:**
- 🔥 Тест с холодным кэшем (2 минуты, 10 VUs)
- 🌡️ Тест с теплым кэшем (3 минуты, 20 VUs)
- 💪 Нагрузочный тест (5 минут, до 50 VUs)

**Что покажет:**
- ✅ Детальная статистика по всем метрикам (avg, min, med, p95, p99, max)
- ✅ Процентное распределение времени между компонентами
- ✅ Статистика попаданий в кэш
- ✅ Количество похожих пользователей
- ✅ Рекомендации по оптимизации

## 🔧 Интерпретация результатов

### Что анализировать

1. **Redis (должен быть быстрым)**
   - ✅ Норма: < 10ms (check + save)
   - ⚠️ Внимание: 10-50ms
   - ❌ Проблема: > 50ms

2. **ClickHouse (основное время выполнения)**
   - Проверка пользователя: < 50ms норма
   - Подсчет взаимодействий: < 50ms норма
   - Поиск похожих пользователей: < 500ms норма, > 1000ms требует оптимизации
   - Получение рекомендаций: < 1000ms норма, > 1500ms требует оптимизации

3. **Алгоритм (должен быть очень быстрым)**
   - ✅ Норма: < 20ms
   - ⚠️ Внимание: 20-50ms
   - ❌ Проблема: > 50ms

4. **Общее время**
   - ✅ Отлично: < 500ms (p95)
   - ⚠️ Приемлемо: 500-2000ms (p95)
   - ❌ Требует оптимизации: > 2000ms (p95)

### Рекомендации по оптимизации

**Если Redis медленный:**
- Проверьте сетевую задержку
- Проверьте нагрузку на Redis
- Рассмотрите Redis Cluster для распределения нагрузки

**Если ClickHouse медленный:**
- Добавьте индексы на часто используемые поля
- Используйте материализованные представления
- Рассмотрите денормализацию данных
- Предварительно рассчитывайте матрицу схожести пользователей

**Если алгоритм медленный:**
- Оптимизируйте Python код
- Рассмотрите использование Cython или Numba
- Уменьшите количество обрабатываемых данных

## 🎓 Дополнительно

Для получения метрик в обычном запросе (не через k6) используйте Swagger UI:

1. Откройте http://localhost:8000/docs
2. Найдите POST `/api/v1/recommendations`
3. Используйте параметр `include_performance_metrics: true`
4. Изучите поле `performance_metrics` в ответе

Или через curl:

```bash
curl -X POST "http://localhost:8000/api/v1/recommendations" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": 1001,
    "top_n": 10,
    "exclude_listened": true,
    "include_performance_metrics": true
  }'
```
