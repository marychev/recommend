## 🆘 Проблемы?

### Все запросы падают?
```bash
# Проверьте что API работает:
curl http://localhost:8000/health

# Укажите правильный URL:
k6 run --env API_URL=http://localhost:8000 load_tests/k6_quick_test.js
```

### Авторизация не работает?
- Проверьте endpoint `/api/v1/auth/login`
- Измените логику авторизации в файле теста
- Используйте свои credentials

### Тест слишком долгий?
```bash
# Используйте быстрый тест:
k6 run load_tests/k6_quick_test.js

# Или укажите короткую длительность:
k6 run --vus 10 --duration 1m load_tests/k6_quick_test.js
```

## 🎓 Ключевые Метрики

### VU (Virtual Users)
Количество одновременно работающих виртуальных пользователей

### Success Rate
Процент успешных запросов (HTTP 200)

### P95 / P99
95-й и 99-й перцентили времени ответа

### RPS
Requests Per Second - запросов в секунду

### Threshold
Пороговое значение метрики (pass/fail)
