## 🚀 Быстрый Старт

### Шаг 1: Установка k6
```bash
# Linux/Mac
brew install k6

# Windows
choco install k6
```

### Шаг 2: Запуск быстрого теста
```bash
cd /Ubuntu/home/recommend
k6 run load_tests/k6_quick_test.js
```

### Шаг 3: Анализ результатов
```bash
# Откройте HTML отчет
open summary_quick_test.html   # Mac
xdg-open summary_quick_test.html  # Linux
start summary_quick_test.html  # Windows
```

### Шаг 4: Запуск полного теста (опционально)
```bash
k6 run load_tests/k6_full_user_scenario_test.js
```

## 🎓 Ключевые Понятия

### VU (Virtual Users)
Виртуальные пользователи - симуляция одновременно работающих пользователей

### Success Rate
Процент успешных запросов (status 200)

### P95, P99
95-й и 99-й перцентили времени ответа

### RPS (Requests Per Second)
Количество запросов в секунду

### Threshold
Пороговое значение для метрики (pass/fail)

## 💡 Советы

1. **Всегда начинайте с быстрого теста** (`k6_quick_test.js`)
2. **Мониторьте сервер** во время тестов (CPU, RAM, DB)
3. **Адаптируйте endpoints** под свой API
4. **Настройте thresholds** под свои требования
5. **Анализируйте HTML отчеты** - там много полезной информации
