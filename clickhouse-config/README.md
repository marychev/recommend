# ClickHouse Configuration

Конфигурация ClickHouse для разработки и тестирования.

## users.xml

Этот файл настраивает пользователя `default` без пароля для удобной разработки.

⚠️ **ВАЖНО**: Эта конфигурация предназначена только для локальной разработки!  
В production всегда используйте надежные пароли.

## Что настроено:

- ✅ Пользователь `default` без пароля
- ✅ Доступ со всех IP адресов (::0)
- ✅ Полные права для разработки
- ✅ Стандартные квоты и профили

## Применение конфигурации:

Конфигурация автоматически монтируется в Docker контейнер через volume:

```yaml
volumes:
  - ./clickhouse-config/users.xml:/etc/clickhouse-server/users.d/users.xml:ro
```

## Пересоздание контейнера:

Если вы изменили конфигурацию, пересоздайте контейнер:

```bash
bash docker-reset-clickhouse.sh
```

## Проверка:

```bash
# Должно подключиться без запроса пароля
curl http://localhost:8123/
```
