# 📊 Сводка проекта

Краткая информация о Music Recommendation System.

## 🎯 Что это?

Рекомендательная система музыкальных треков на основе **Collaborative Filtering** с использованием современного технологического стека.

## ✨ Основные возможности

1. **Сбор событий** - Прием и обработка действий пользователей (play, like, skip, etc.)
2. **Аналитика** - Хранение и анализ больших объемов данных в ClickHouse
3. **Рекомендации** - ML-based персонализированные рекомендации
4. **REST API** - Полнофункциональный API с Swagger документацией
5. **Тестирование** - 60+ автоматических тестов

## 🎯 Алгоритм рекомендаций

**Collaborative Filtering (User-Based)**

1. Строим user-item матрицу с неявными рейтингами
2. Находим похожих пользователей (косинусное сходство)
3. Рекомендуем треки, которые понравились похожим пользователям
4. Ранжируем по релевантности

**Веса действий:**
```
play: +1.0
like: +3.0
dislike: -3.0
skip: -0.5
add_to_playlist: +2.0
share: +2.5
```
