# Отключение подкачки (swap) в WSL

## Зачем отключать

- Swap на диске в **сотни раз медленнее** RAM
- Docker-контейнеры (ClickHouse, Kafka) начинают зависать когда данные уходят в swap
- Лучше получить ошибку OOM и узнать о проблеме, чем молча тормозить

## Как отключить в WSL2

Создать/отредактировать файл `C:\Users\<USERNAME>\.wslconfig`:

```ini
[wsl2]
swap=0
```

Затем в PowerShell:
```powershell
wsl --shutdown
```

И заново открыть терминал.

## Временное отключение внутри Linux

```bash
sudo swapoff -a
```

## Проверка текущего состояния

```bash
free -h          # Показывает RAM и Swap
swapon --show    # Показывает активные swap-разделы
```

## Когда НЕ стоит отключать

- Если RAM < 8GB — без swap система будет убивать процессы (OOM killer)
- Если запускается много тяжёлых контейнеров одновременно

При 16GB+ RAM можно смело отключать.
