## 🎯 Функциональность

### 1. Список пользователей

**Особенности:**
- ✅ Загрузка до 1000 пользователей
- ✅ Поиск в реальном времени (по имени и email)
- ✅ Пагинация (10 пользователей на страницу)
- ✅ Кнопка обновления списка
- ✅ Активное выделение выбранного пользователя
- ✅ Плавная анимация при наведении

**Карточка пользователя:**
```
┌─────────────────────────┐
│ john_doe                │ ← Имя (жирный шрифт)
│ john@example.com        │ ← Email (серый)
└─────────────────────────┘
```

### 2. Поиск

**Работает по:**
- Имени пользователя (username)
- Email адресу
- Без учета регистра
- В реальном времени (без задержки)

**Состояния:**
- Пустой → показаны все пользователи
- С текстом → фильтрация + обновление пагинации
- Нет результатов → "Пользователи не найдены"

### 3. Профиль пользователя

**Заголовок с градиентом:**
```
┌──────────────────────────────────────┐
│  ◉   john_doe                        │
│      john@example.com                │
│      🎂 25 лет  🌍 Россия  📅 С 2024│
└──────────────────────────────────────┘
```

**Элементы:**
- Аватар (первая буква имени в круге)
- Имя пользователя (крупный шрифт)
- Email
- Мета-информация:
  - Возраст (с правильным склонением: год/года/лет)
  - Страна
  - Год регистрации

### 4. Статистика

**4 блока метрик:**

```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│    1,234    │     456     │    12.5     │    Rock     │
│Взаимодейств.│   Треков    │    Часов    │Любимый жанр │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

**Особенности:**
- Большие цифры (цвет primary)
- Автоматическое форматирование (1,234)
- Анимация при наведении (поднимается вверх)
- Адаптивная сетка (4 → 2 → 1 колонка)

### 5. Рекомендации

**Генерация:**
- Кнопка "Сгенерировать рекомендации"
- Индикатор загрузки (спиннер + текст)
- Toast уведомление об успехе/ошибке

**Мета-информация:**
- Алгоритм:
  - "Коллаборативная фильтрация" (collaborative_filtering)
  - "На основе популярности" (popular_based)
- Время генерации (формат: 04.11.2025, 12:30:45)

**Карточка трека:**

```
┌────────────────────────────────────────────────────┐
│ 1. Bohemian Rhapsody                         85%   │
│    🎤 Queen                            релевантность│
│    💿 A Night at the Opera  🎵 Rock  ⏱️ 5:54      │
│    📅 1975                                         │
│    "Пользователи с похожими вкусами слушают..."   │
└────────────────────────────────────────────────────┘
```

**Элементы карточки:**
- Номер в списке
- Название трека (жирный)
- Исполнитель (иконка 🎤)
- Альбом (иконка 💿)
- Жанр (иконка 🎵)
- Длительность в формате M:SS (иконка ⏱️)
- Год выпуска (иконка 📅)
- Причина рекомендации (курсив, серый)
- Оценка релевантности (в процентах, градиент)

**Анимации:**
- Плавное появление
- Сдвиг вправо при наведении
- Тень при наведении

## 🔔 Уведомления (Toast)

**Типы:**
- ✅ Success (зеленая граница)
- ❌ Error (красная граница)
- ℹ️ Info (синяя граница)

**Поведение:**
- Появляется справа внизу
- Автоматически исчезает через 3 секунды
- Плавная анимация появления/исчезновения

**Примеры:**
- "Список пользователей обновлен" (success)
- "Рекомендации успешно сгенерированы" (success)
- "Ошибка при загрузке пользователей" (error)
- "Ошибка при генерации рекомендаций" (error)

## ⚡ Производительность

### Оптимизации
- Пагинация: только 10 пользователей на странице
- Фильтрация на клиенте (быстро)
- Кэширование: пользователи загружаются один раз
- Минимальные перерисовки DOM
- Параллельная загрузка (Promise.all)

### Скорость
- Загрузка пользователей: ~200ms
- Переключение пользователя: ~100ms
- Генерация рекомендаций: ~200ms
- Поиск: мгновенно (без задержки)

### Тени
- `shadow` - стандартная тень
- `shadow-lg` - большая тень (модальные окна, карты)

## 🔧 Технические детали

### Архитектура

**State Management:**
```javascript
const state = {
  users: [],           // Все загруженные пользователи
  currentUser: null,   // Выбранный пользователь
  currentPage: 1,      // Текущая страница
  pageSize: 10,        // Размер страницы
  searchQuery: '',     // Поисковый запрос
  allUsers: []         // Бэкап всех пользователей
};
```

**Event Handlers:**
- `searchUser.input` - поиск в реальном времени
- `refreshUsers.click` - обновление списка
- `prevPage/nextPage.click` - пагинация
- `userItem.click` - выбор пользователя
- `generateRecommendations.click` - генерация

**API Calls:**
```javascript
GET /api/v1/users?limit=1000
GET /api/v1/users/{user_id}
GET /api/v1/users/{user_id}/statistics
GET /api/v1/recommendations/{user_id}
```

### Безопасность

**XSS Protection:**
```javascript
function escapeHtml(text) {
  const div = document.createElement('div');
  div.textContent = text;
  return div.innerHTML;
}
```

Все пользовательские данные экранируются перед вставкой в DOM.

### Обработка ошибок

**Уровни:**
1. Network errors (fetch)
2. HTTP errors (response.ok)
3. Empty data (no users/recommendations)
4. User feedback (toast notifications)

**Стратегия:**
```javascript
try {
  // API call
} catch (error) {
  console.error()      // Логирование
  showError()          // UI feedback
  showToast(, 'error') // Уведомление
}
```

## 🎓 Примеры использования

### 1. Поиск пользователя
```
1. Введите "john" в поле поиска
2. Список автоматически отфильтруется
3. Кликните на найденного пользователя
```

### 2. Просмотр статистики
```
1. Выберите любого пользователя
2. Посмотрите статистику в центральной панели
3. Обратите внимание на любимый жанр
```

### 3. Получение рекомендаций
```
1. Выберите пользователя с взаимодействиями
2. Нажмите "Сгенерировать рекомендации"
3. Подождите 1-2 секунды
4. Изучите рекомендации и их причины
```

### 4. Навигация по страницам
```
1. Нажмите "Вперед →" для следующей страницы
2. Нажмите "← Назад" для предыдущей страницы
3. Номер страницы отображается по центру
```
