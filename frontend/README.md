# Frontend - Music Recommendation System UI

Веб-интерфейс для просмотра пользователей и их музыкальных рекомендаций.

## 🚀 Быстрый старт

### 1. Запустите бэкенд API

Убедитесь, что API запущено на порту 8000:

```bash
# Из корневой директории проекта
python -m app.main
```

API будет доступно по адресу: http://localhost:8000

### 2. Откройте frontend

Просто откройте файл `index.html` в браузере:

```bash
# Windows
start frontend/index.html

# Linux
xdg-open frontend/index.html

# macOS
open frontend/index.html
```

Или запустите простой HTTP сервер:

```bash
# Python 3
cd frontend
python -m http.server 8080

# Затем откройте: http://localhost:8080
```

## ✨ Возможности

### 1. Список пользователей
- Просмотр всех пользователей системы
- Поиск по имени или email
- Пагинация (10 пользователей на страницу)
- Обновление списка

### 2. Профиль пользователя
- Аватар с первой буквой имени
- Основная информация: имя, email, возраст, страна
- Дата регистрации

### 3. Статистика
- Общее количество взаимодействий
- Количество уникальных прослушанных треков
- Общее время прослушивания (в часах)
- Любимый жанр

### 4. Рекомендации
- Генерация персонализированных рекомендаций
- Информация об алгоритме (коллаборативная фильтрация / популярные треки)
- Время генерации
- Для каждого трека:
  - Название, исполнитель, альбом
  - Жанр, длительность, год выпуска
  - Оценка релевантности (score)
  - Причина рекомендации

## 🔧 Конфигурация

API URL настроен в файле `app.js`:

```javascript
const API_BASE_URL = 'http://localhost:8000/api/v1';
```

Если API запущено на другом хосте/порте, измените эту константу.

## 📡 API Endpoints

Используются следующие эндпоинты:

- `GET /api/v1/users?limit=1000` - список всех пользователей
- `GET /api/v1/users/{user_id}` - информация о пользователе
- `GET /api/v1/users/{user_id}/statistics` - статистика пользователя
- `GET /api/v1/recommendations/{user_id}` - генерация рекомендаций

## 🐛 Устранение неполадок

### API недоступен

**Проблема**: Ошибка загрузки пользователей

**Решение**:
1. Убедитесь, что API запущено: http://localhost:8000/docs
2. Проверьте, что используется правильный порт в `app.js`
3. Проверьте консоль браузера (F12) на наличие CORS ошибок

### CORS ошибки

Если браузер блокирует запросы из-за CORS, убедитесь что:
1. API настроено с CORS middleware
2. Или используйте HTTP сервер для фронтенда (не открывайте файл напрямую)

### Нет данных

**Проблема**: Пользователи не отображаются

**Решение**:
1. Убедитесь, что в базе данных есть пользователи
2. Запустите скрипт `seed_data.py` для создания тестовых данных:
   ```bash
   python scripts/seed_data.py
   ```

## 📝 Технические детали

### Архитектура

Приложение построено по принципу SPA (Single Page Application):
- **State management**: Простой объект состояния
- **Rendering**: Динамическая генерация HTML через JavaScript
- **API calls**: Fetch API с async/await
- **Error handling**: Try-catch блоки и toast уведомления

### Производительность

- Ленивая загрузка: данные загружаются только при необходимости
- Пагинация: отображается максимум 10 пользователей
- Кэширование: пользователи загружаются один раз
- Оптимизация DOM: минимальное количество перерисовок
