## 🔧 Выполненные оптимизации

### 1. Исправления Kafka Producer

#### Проблема
- `AIOKafkaProducer.__init__() got an unexpected keyword argument 'retries'`
- Kafka недоступна при старте приложения
- Pending tasks в тестах

#### Решение
- ✅ Удален невалидный параметр `retries` из `AIOKafkaProducer`
- ✅ Добавлена retry логика с exponential backoff в `connect_kafka()`:
  - До 5 попыток подключения
  - Задержки: 1s, 2s, 4s, 8s, 16s (обычный режим)
  - Задержки: 0.1s, 0.2s, 0.4s (fast_mode для тестов)
- ✅ Добавлен healthcheck для Kafka в `docker-compose.yml`
- ✅ Улучшено закрытие producer/consumer с таймаутами

#### Файлы
- `app/kafka/client.py` - retry логика, улучшенное закрытие
- `app/kafka/producer.py` - таймауты для подключения
- `docker-compose.yml` - healthcheck для Kafka

### 2. Оптимизация ClickHouse запросов

#### Проблема
- **Code: 241** - Memory limit exceeded при нагрузочных тестах
- Запросы рекомендаций падают при параллельной нагрузке (10 VU)
- Нет fallback механизма при ошибках памяти

#### Решение

##### 2.1. Добавлены SETTINGS в запросы
```sql
SETTINGS 
    max_memory_usage = 2000000000,                    -- 2GB на запрос
    max_bytes_before_external_group_by = 1000000000, -- Использование диска
    max_bytes_before_external_sort = 1000000000      -- Внешняя сортировка
```

**Применено к:**
- Запрос похожих пользователей (`similar_users_query`)
- Запрос рекомендаций (`recommendations_query`)
- Запрос популярных треков (`get_popular_recommendations`)

##### 2.2. Оптимизация запроса похожих пользователей
- Добавлен `LIMIT 1000` в CTE `user_tracks` для ограничения данных
- Снижает нагрузку на память при обработке больших матриц

##### 2.3. Fallback механизм
- При ошибке памяти (Code: 241) система автоматически возвращает популярные треки
- Пользователь получает ответ вместо ошибки 500
- Логируется предупреждение для мониторинга

#### Файлы
- `app/routers/recommendations.py` - оптимизированные запросы и fallback

## 🔍 Технические детали

### Kafka Retry Logic
```python
# Обычный режим: 5 попыток с задержками 1s, 2s, 4s, 8s, 16s
# Fast режим: 3 попытки с задержками 0.1s, 0.2s, 0.4s
await connect_kafka(fast_mode=True)  # Для тестов
```

### ClickHouse Memory Settings
- **max_memory_usage**: 2GB на запрос (достаточно для сложных JOIN)
- **max_bytes_before_external_group_by**: 1GB (использует диск при превышении)
- **max_bytes_before_external_sort**: 1GB (внешняя сортировка на диске)

### Fallback Strategy
```python
if "Code: 241" in error_str or "MEMORY_LIMIT_EXCEEDED" in error_str:
    # Автоматический fallback на популярные треки
    return await get_popular_recommendations(...)
```
